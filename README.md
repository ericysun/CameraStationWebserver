# Camera Station Webserver
- Webserver for Camera Stations, allowing live viewing of camera feed from ESP32 camera view, and changing of camera settings.
- Webserver functions as a wifi network that the user can connect to. Once they go to the IP address of the camera station site, they can utilize the server.
